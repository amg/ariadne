# Ari

Ari is a chat app for talking to AI models. It shows what every reply costs,
notices when you change the subject, and, if you let it, remembers what
matters about you for your next conversation.

The code, the setup guide and the design decisions live in the
[repository](https://github.com/amg/ariadne). These pages hold the diagrams
that need a browser to read:

- **[aws-prod architecture](architecture/aws-prod-architecture.html)** — The multi-copy AWS deployment: services, the way in, why Valkey
- **[Load testing architecture](architecture/load-testing-architecture.html)** — How a load run is driven, recorded and judged
